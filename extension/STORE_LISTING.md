**Özellikler:**

✅ **Otomatik Navigasyon**: Microsoft Security Center ve Exchange Admin Portal'da otomatik gezinme
✅ **Akıllı Tıklama**: Element bulma ve otomatik tıklama sistemi
✅ **Gerçek Zamanlı Doğrulama**: Her adımda otomatik kontrol ve doğrulama

✅ **Çoklu Workflow Desteği**: 6 farklı workflow türü için otomatik yapılandırma

**Desteklenen Workflow'lar:**

1. **Third-Party Phishing Simulations** - Phishing simülasyon domain ve IP'lerini allow list'e ekleme
2. **Anti-Spam Policies** - Connection Filter Policy yapılandırması
3. **Safe Links** - Safe Links policy oluşturma ve domain ekleme
4. **Spam Filter Bypass** - Exchange transport rules ile IP-based bypass

🔒 Kaynak kodu açık ve şeffaf

**Kullanım:**

1. Microsoft Security Center (`https://security.microsoft.com`) veya Exchange Admin Portal (`https://admin.exchange.microsoft.com`) sayfasına gidin

### English Version

**Keepnet Assistant - Office 365 Allow List Configuration Assistant**

Keepnet Assistant is a powerful Chrome extension that automates allow list configuration for Keepnet phishing simulations in Office 365 environments.

**Features:**

✅ **Automatic Navigation**: Auto-navigation in Microsoft Security Center and Exchange Admin Portal
✅ **Smart Clicking**: Element detection and automatic clicking system
✅ **Real-time Validation**: Automatic checks and validation at each step
✅ **Screenshot Evidence**: Automatic screenshot capture for each step
✅ **Multiple Workflow Support**: Automatic configuration for 6 different workflow types

**Supported Workflows:**

1. **Third-Party Phishing Simulations** - Add phishing simulation domains and IPs to allow list
2. **Anti-Spam Policies** - Connection Filter Policy configuration
3. **Safe Links** - Safe Links policy creation and domain addition
4. **Spam Filter Bypass** - IP-based bypass via Exchange transport rules
5. **ATP Link Bypass** - Advanced Threat Protection link bypass rules
6. **ATP Attachment Bypass** - Advanced Threat Protection attachment bypass rules

**Security & Privacy:**

🔒 All data stored locally only
🔒 No data sent to external servers
🔒 Works only on Microsoft Office 365 pages
🔒 Open source and transparent

**Usage:**

1. Navigate to Microsoft Security Center (`https://security.microsoft.com`) or Exchange Admin Portal (`https://admin.exchange.microsoft.com`)
2. Click the extension icon
3. Assistant panel will open
4. Click "Start" button to begin workflow
5. Follow step-by-step instructions

**Requirements:**

- Office 365 admin account
- Access to Microsoft Security Center and Exchange Admin Portal
- Chrome browser
